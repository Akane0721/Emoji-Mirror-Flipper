# Emoji-Mirror-Flipper

方便快捷的对称表情包生成 web 应用，再也不用在群里找对称 bot 了。

![](example.png)

## 快速开始

**双击 `run.bat`** 运行。

首次运行会自动创建虚拟环境并装依赖（需要本机有 Python 3.9+），之后每次浏览器会自动打开
<http://127.0.0.1:5000/>。关掉黑窗口或按 `Ctrl+C` 停止。

手动运行：

```bash
pip install -r requirements.txt
python app.py
```

## 功能

* 拖拽、点击选择、或者直接 `Ctrl+V` 粘贴图片
* 支持 **jpg / png / gif / webp**，单文件上限 25MB
十二种对称方式：

| 效果 | 说明 | 输出尺寸 |
|---|---|---|
| ➡️⬅️⬇️⬆️ 单轴对称 | 左→右、右→左、上→下、下→上 | 保持原比例 |
| ↘️↗️ 对角对称 | 沿主对角线或副对角线翻折 | 正方形 |
| 🪟 四重存在 | 左右加上下，四个象限全对称 | 保持原比例 |
| 🔮 万华镜 | n 重二面体对称，4 / 6 / 8 / 12 / 16 瓣 | 正方形 |
| 🌀 风车 | 只旋转不镜像，有旋向；支持 3 / 5 奇数叶 | 正方形 |
| 🌪️ 螺旋 | 风车加上对数扭曲，2–12 臂，扭曲 0–720° | 正方形 |
| 🧱 镜面平铺 | 缩小后镜像铺满，2 / 3 / 4 / 6 格 | 保持原比例 |
| 🪷 窗花 | 每格都是完整的八向对称花纹，2 / 3 / 4 / 6 格 | 保持原比例 |

万华镜、风车和螺旋还能调**起始角**，决定从源图哪一瓣扇形取样，拖动滑块即可换出完全不同的花纹。

「格数」指**每条边切成几格**，所以 6 格 = 6×6 = 36 份，不是 6 份。

### 效果可以叠加

打开面板上的「＋ 叠加」后，点击效果会追加到流程末尾而不是替换，最多串 4 个。流程以可点选的 chip 展示，点某一步就编辑它的参数，点 ✕ 移除。

**顺序有意义** —— 因为对角和径向模式会把画面裁成正方形，`万华镜 → 镜面平铺` 和 `镜面平铺 → 万华镜` 结果完全不同。

* 切效果即时预览，原图和结果并排对比，透明区域用棋盘格衬底显示
* 一键下载
* 动图保留原本的**帧间隔**和循环次数，透明通道不会变黑
* 上传和输出的临时文件超过 6 小时会自动清理

`mirror.py` 也可以直接调用：

```python
from pathlib import Path
from mirror import KALEIDO, PINWHEEL, QUAD, SPIRAL, TILE, PAPERCUT, flip, probe

src = Path("target.gif")
info = probe(src)                                  # validates that it really is an image

flip(src, Path("out.gif"), "l2r", info.animated)                 # 单轴镜像
flip(src, Path("diag.gif"), "d1", info.animated)                 # 主对角
flip(src, Path("quad.gif"), QUAD, info.animated)                 # 四重存在
flip(src, Path("tile.gif"), TILE, info.animated, count=3)        # 镜面平铺
flip(src, Path("cut.gif"), PAPERCUT, info.animated, count=3)     # 窗花
flip(src, Path("kal.gif"), KALEIDO, info.animated,               # 万华镜
     count=8, offset=45)
flip(src, Path("pw.gif"), PINWHEEL, info.animated,               # 风车
     count=5, offset=0)
flip(src, Path("sp.gif"), SPIRAL, info.animated,                 # 螺旋
     count=6, offset=0, twist=180)
```

效果链用 `flip_chain()`，步骤按顺序应用：

```python
from mirror import KALEIDO, Step, flip_chain

flip_chain(src, Path("combo.gif"),
           [Step("d1"), Step(KALEIDO, count=6, offset=45)],
           info.animated)
```

## 万华镜和风车是怎么做的

两者共用同一套径向合成流程，区别只在中间那一步镜像。

1. 以中心裁成正方形（所以输出会变成 `min(宽, 高)` 的正方形）
2. 从 `起始角` 开始切出一个 `360/n` 度的扇形楔块
3. **万华镜**：把楔块沿水平中轴镜像，得到跨度 `2×360/n` 的「单元」，再绕中心旋转 `n/2` 次铺满一圈
   **风车**：跳过镜像，直接把楔块绕中心旋转 `n` 次
4. 中心裁回原尺寸

第 3 步那次镜像决定了成品的性格。万华镜因此有 **n 条过中心的镜像轴**，看起来端正、静止；风车没有任何镜像轴，只有旋转对称，于是带上了旋向和动势。也正因为要镜像，**万华镜的瓣数必须是偶数**（否则单元没法整除一整圈），而风车没这个限制，可以用 3 或 5 叶。

**起始角**决定从源图的哪一瓣取样。楔块以外的内容不会出现在结果里 —— 这是径向对称的固有特性，所以同一张图换个角度可能面目全非。

两个实现细节：

* 楔形遮罩在 4 倍尺寸下绘制再缩回，避免两条放射状边缘出现锯齿。
* 合成在放大 √2 倍的画布上进行，最后才裁回原尺寸。否则从边缘中点方向取的楔块只有 `size/2` 的半径，而输出的四角在 `size×0.707` 处，凡是旋转步长不是 90° 整数倍的瓣数都会把空白转进角落。

## 🌪️ 螺旋是怎么做的

先按风车拼出 n 臂图案，再叠一层**对数扭曲**：每个像素绕中心旋转的角度只跟它到中心的距离有关，越靠近中心转得越多。

这一步**不会破坏对称性**。绕中心的扭曲只改变角度、不改变半径，因此和"绕同一中心旋转"是可交换的 —— 原图有 n 重旋转对称，扭曲后依然有。所以螺旋是货真价实的对称模式，不是单纯的形变。（但镜像轴会被破坏，因为扭曲有旋向，所以螺旋建立在风车而非万华镜之上。）

扭曲在**内切圆**处衰减到 0，不是在四角。这个边界很关键：旋转保持半径不变，内切圆里的点转到哪儿都还在圆里，必定有源像素可采；如果让它在对角半径处才归零，靠近四角的点就会被转到方形覆盖不到的位置，结果上会出现透明空洞。

实现上是一次 Pillow 的 `Image.MESH` 变换，把画面切成 56×56 的网格算好每格的源四边形，剩下的插值由 Pillow 的 C 代码完成 —— 不需要逐像素循环，也不需要引入 numpy。829×865 的图约 0.4 秒。

## 两种平铺是怎么做的

两者都保持原图尺寸和宽高比，所以适合万华镜裁成正方形后就没剩什么内容的横图或竖图。

**「格数」是每条边的格子数**，不是可见图案的个数。`n = 6` 意味着单元格边长是 `ceil(宽/6) × ceil(高/6)`，一共铺 `6×6 = 36` 份。

### 🧱 镜面平铺

把整张图缩到 `1/n`，铺 `n×n` 份，**相邻两格互为镜像**：奇数列水平翻转、奇数行垂直翻转。这样任意两格交界处的那一列（或一行）像素完全相同，接缝看不出来；直接重复而不翻转的话，每条缝都是一道硬边。

因为对称性来自"相邻格互为镜像"，一个完整的对称图案要跨 **2×2 个格子**才凑齐 —— 所以 6×6 格看起来像 3×3 个图案。

### 🪷 窗花

名字来自剪纸窗花，因为做法完全一样：**把纸折到八分之一，剪开，再展开**，就得到四向对称的花样。

所以它和镜面平铺有个本质区别 —— **只用到原图中心正方形的八分之一**，其余全部丢弃。镜面平铺保留整张图，窗花是拿一小块折出一个纹样再铺满。

| | 镜面平铺 | 窗花 |
|---|---|---|
| 用到原图多少 | 全部 | 只有 1/8 |
| 单格是什么 | 缩小的原图 | 折出来的抽象纹样 |
| 图案在哪成形 | 跨 2×2 格 | 每格独立成形 |

每个格子自身带有正方形的完整 **D4 对称**（横、竖、两条对角线共四条镜像轴）。

关键是折叠的层级。**直接把整个正方形沿对角线折是错的** —— 对角折会丢弃一整个三角形，把之前建立的横竖对称一并破坏掉。D4 的基本域是正方形的**八分之一**，所以要降一级折：先把**单个象限**沿它自己的对角线折成对称，再把这个象限镜像展开到另外三个象限。

这样得到的格子四条边两两相同，直接重复就能对齐，连交替翻转都不需要。

### 2026-08-26（五）

**新增：效果叠加**

* 效果可以串成流程，最多 4 步，按顺序应用。API 从单个 `mode` 扩展为 `steps` 数组，`mirror.py` 新增 `Step` 与 `flip_chain()`

* 下载文件名按步骤拼接，如 `主对角对称_万华镜6瓣45度.png`

### 2026-08-26（四）

**新增**

* 「处理中…」移到结果面板标题栏，不再挤在按钮行里
* 模式按钮改用更紧凑的圆角矩形，与面板下方的动作按钮区分开

**修复**

* 螺旋最初让扭曲在对角半径处才衰减到 0，导致靠近四角的点被转到方形覆盖不到的位置，出现透明空洞（180° 时 4.8%，720° 时 9.2%）。改为在内切圆处归零后，各扭曲档位空洞占比均为 0

### 2026-08-26（三）

**新增**

* **🪷 窗花**（`PAPERCUT`）：像剪纸窗花那样把中心正方形折到八分之一再展开，得到带四条镜像轴（D4）的纹样，然后铺满画面。每格都是独立完整的花样，直接重复即可对齐。2 / 3 / 4 / 6 格，保持原图宽高比

**过程中修掉的问题**
