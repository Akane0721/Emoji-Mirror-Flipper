# Emoji-Mirror-Flipper

方便快捷的对称表情包生成 web 应用，从此再也不用担心在群里找对称 bot 发图时被群友看见尴尬了。

![](example.png)

## 快速开始

**双击 `run.bat`** 就行。

首次运行会自动创建虚拟环境并装依赖（需要本机有 Python 3.9+），之后每次都是秒启动，浏览器会自动打开
<http://127.0.0.1:5000/>。关掉黑窗口或按 `Ctrl+C` 停止。

想手动跑：

```bash
pip install -r requirements.txt
python app.py
```

## 功能

* 拖进来、点击选择、或者直接 `Ctrl+V` 粘贴剪贴板里的图
* 支持 **jpg / png / gif / webp**，单文件上限 25MB
* 四个方向：左→右、右→左、上→下、下→上
* 切方向即时预览，原图和结果并排对比，透明区域用棋盘格衬底显示
* 一键下载
* 动图保留原本的**帧间隔**和循环次数，透明通道也不会变黑
* 上传和输出的临时文件超过 6 小时会自动清理

## 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `EMF_PORT` | `5000` | 端口 |
| `EMF_HOST` | `127.0.0.1` | 监听地址 |
| `EMF_NO_BROWSER` | 未设置 | 设为 `1` 则不自动开浏览器 |

## 注意

这个服务默认只监听 `127.0.0.1`，只能本机访问。**不要**把 `EMF_HOST` 改成 `0.0.0.0`
暴露到公网 —— 它用的是 Flask 自带的开发服务器，没有做任何鉴权和限流。

## 结构

```
app.py              Flask 路由和 API
mirror.py           镜像对称核心逻辑（可以单独当模块用）
templates/index.html  单页前端
run.bat             一键启动脚本
uploads/ output/    运行时临时文件，自动清理
```

`mirror.py` 也可以直接调用：

```python
from pathlib import Path
from mirror import flip, probe

src = Path("target.gif")
info = probe(src)                                  # validates that it really is an image
flip(src, Path("out.gif"), "l2r", info.animated)
```

## 更新记录

### 2026-07-29

一次大修，功能、健壮性和易用性都做了处理。

**新增**

* `run.bat` 一键启动：双击即用，首次运行自动创建虚拟环境并安装依赖，之后秒启动并自动打开浏览器
* 上下方向对称（`上→下`、`下→上`），此前只有左右
* 前端重做成单页：拖拽上传、`Ctrl+V` 粘贴剪贴板图片、切方向即时预览、原图与结果并排、透明区棋盘格衬底、一键下载、深色模式自适应
* 支持 webp 输入
* `requirements.txt`、`.gitignore`
* 可通过 `EMF_PORT` / `EMF_HOST` / `EMF_NO_BROWSER` 配置
* 重复启动时不再报端口占用，直接指向已在运行的实例
* 上传和输出的临时文件超过 6 小时自动清理

**修复**

* **奇数尺寸丢列**：原先取半用 `width // 2`，宽或高为奇数时中间一列/行没有被覆盖，输出有黑缝。改用向上取整，中间行列被两次粘贴为同值，无缝且不错位
* **透明变黑**：原先固定 `Image.new('RGB')`，png/gif 的透明区域会变成黑色。现在全程 RGBA，仅在输出 JPEG 时才合成白底
* **GIF 帧间隔丢失**：保存动图时未传 `duration`，输出会退化成默认播放速度。现在逐帧保留原始间隔和循环次数
* **路径穿越**：上传时直接取用户文件名的后缀拼进保存路径，构造特殊文件名可将文件写出 `uploads/` 之外。现在文件名完全由 uuid4 生成、扩展名取自实际探测到的图片格式，客户端提供的名字仅用于界面显示
* **`debug=True` 上线**：Werkzeug 调试器可通过浏览器执行任意代码，已关闭
* 缺少 `file` 字段时不再 500，返回 400
* 新增 25MB 上传上限和 5000 万像素上限（防解压炸弹）
* 上传内容按实际格式校验，不再只看扩展名

**清理**

* 删除 `mirror.html`、`upload_failed.html`（三份重复 CSS，且存在 `/* /* */` 嵌套坏注释）
* 移除 `mirror.py` 中残留的模块级无用变量和注释掉的调用
* 取消跟踪误提交的 `__pycache__` 和 `uploads/` `output/` 下的示例文件
* 代码注释统一为英文
